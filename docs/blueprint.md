# **App Name**: Colacsan Cable Comparator

## Core Features:

- URL Upload: Allow users to submit URLs (e.g. com website from prompt) to be scraped and analyzed.
- Text Extraction: Scrape content from the submitted URLs using a headless browser, extracting relevant textual data such as bills.
- Bill Comparison: Leverage a generative AI tool to compare the features from each cable network to user preferences.
- Recommendation Engine: Based on user preferences and bill details, recommend the most suitable cable network options.
- Data Visualization: Visually represent the comparison results using charts or tables, highlighting key differences and savings.
- Preference Storage: Store the user's comparison preferences (e.g., desired features, budget limits) locally.

## Style Guidelines:

- Primary color: Light blue (#55acee) for a calm, trustworthy feel, inspired by communication and clarity.
- Background color: Very light blue (#f0f8ff) for a clean and airy feel, contrasting subtly with the primary.
- Accent color: Yellow-gold (#FFD700) to highlight key information and call to actions, suggesting value and benefit.
- Body and headline font: 'Inter', a sans-serif font, which ensures readability.
- Use minimalistic, consistent icons related to communication, networking, and cost savings.
- Employ a clean, intuitive layout that emphasizes readability and comparison, and makes use of whitespace.
- Subtle animations can enhance the user experience (e.g., transitions during bill comparisons) without being distracting.
